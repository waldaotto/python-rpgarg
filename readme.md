## 🎮 About the Project

A custom RPG game that combines **Deck Builder** mechanics with classic RPG elements.

The project is being developed in Python, using Tkinter for the graphical interface and SQLite3 for data storage.

The game will feature its own custom engine, developed according to the needs of the project. This will allow custom mechanics, rules, and systems to be implemented without relying on an external game engine.

## ⚔️ Game Concept

The project combines two main gameplay styles:

- **Deck Builder:** deck building, cards, abilities, and combat strategies.
- **Classic RPG:** characters, attributes, equipment, progression, and exploration.

The game mechanics will be developed from scratch, allowing complete freedom when designing and evolving the game's systems.

## 🧠 Knowledge Applied

The project involves several areas of programming, software architecture, and system development.

- **Object-Oriented Programming (OOP):** organizing the code using classes, objects, attributes, and methods.
- **Software Architecture:** separation of responsibilities and modular code organization.
- **Programming Logic:** implementing game rules, conditions, and mechanics.
- **Data Structures:** using lists, dictionaries, and other structures to manage cards, characters, and game states.
- **Relational Databases:** designing tables, relationships, and data integrity using SQLite3.
- **SQL:** performing queries and database operations such as insertion, updating, and deletion.
- **Graphical User Interfaces:** creating windows, components, and events using Tkinter.
- **Design Patterns:** applying appropriate design patterns according to the project's needs.
- **Version Control:** managing the development history using Git.

## 🏗️ Development

The project will be developed using a modular structure, aiming to separate the graphical interface, game logic, and database access.

The custom engine will be developed progressively according to the game's requirements, allowing new systems and mechanics to be added without compromising the organization of the project.
